# Biblioteca de ícones 3D dos mapas (GPT Image, fundo removido, 512x512 PNG)
Antes de gerar um ícone novo, veja se um destes serve. Gerar: `bash scripts/gerar_icone.sh <nome> "<descrição em inglês>"` (~2,75 créditos). Usar num mapa: ponha o nome do arquivo (sem .png) no campo `emoji` do roteiro; o `scripts/montar.py` copia o ícone daqui sozinho.
